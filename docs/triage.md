# Triage log

_Every incoming task, wherever it came from (chat, a teammate, a ticket, a run, a store review, monitoring),
sorted before any work. Newest first. IDs are TR-nnn and are never reused. People are named by role only; names
and emails of real users stay out of this file. Format and rules: [SDLC-GUIDE.md, 7.1](../SDLC-GUIDE.md#71-docstriagemd-the-triage-log)._

**Columns.** _Source_: where it came from. _Raised by_: role. _Module_: the system review it belongs to.
_Verdict_: bug, change, question, not a bug, duplicate. _Why_: what the code or a run shows, with file and line.
_Path_: **light** (a fix with a build note) or **full** (intent, spec and plan first, because it changes what the
product does); — when no work follows. _Change_: link to the change folder. _State_: open, building,
built (branch), merged (PR n), closed (reason).

A cell that needs a `|` writes it as `\|`.
