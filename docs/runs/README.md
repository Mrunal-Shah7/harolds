# Runs

One file per checklist run, named `YYYY-MM-DD-<checklist-or-change>.md`, listed newest first in
[../README.md](../README.md). How runs are done: [../testing.md](../testing.md). Template:
[_template.md](_template.md).

Results are `pass`, `fail`, `blocked`, `not checked` or `YOU`. A `fail` gets a triage line unless the system
review already lists it as a known problem. A run log is never edited after the run, except to add the triage IDs
it led to; a re-run is a new file. Screenshots that show personal data stay out of the repository.
