What v1.1 keeps — the bones

  • The four-surface logic (paper / paper-sunk / surface / roast), band rhythm, and at least one roast band per page.
  • All tokens verbatim from the v1.0 frontmatter — nothing renamed, nothing added to the palette.
  • The four faces and their jobs: Alfa Slab One poster, Baloo 2 display, Inter body, JetBrains Mono utility.
  • The ticket chip as the signature, identical across confirmation, kitchen card, and admin tables.
  • Prices in ink, brand as accent only, blue focus, no gradients/glass/blur, KDS dark scope with full-weight modifiers and printed elapsed minutes.

    • What v1.1 evolves — proposed design.md amendments

  • 1. Weave texture as zero-asset CSS. Two crossed 1px repeating-linear-gradients at 3.5% ink on light band roots. Resolves Open Input #6 with no asset, no request, no CSP change. If the tiling PNG ever arrives it can replace this one rule.
  • 2. Board leaders. A dotted rule binding a name to its price in totals/receipt contexts (checkout summary, admin order detail). Functional, not decorative — it encodes board-only pricing, the same way the chip encodes the ticket. Dots, never dashes; the dashed border stays exclusive to the chip. Requires amending §6's "only decorative element" sentence to name both system elements.
  • 3. Chip construction. Notched corners are now real (clip-path octagon) with the dashed flame rule following the notch, instead of square corners approximating the spec.
  • 4. Poster face confirmed. Alfa Slab One shipped throughout this preview; Bevan not loaded. Closes Open Input #7 pending Manav's sign-off.
  • 5. Hero voice. Three stacked poster lines with one brand-red accent line — spends red once, in type, instead of on a component.
  • 6. Storefront dark scheme — amends §8. The dark-mode prohibition is lifted for the storefront only: an opt-in scheme, light by default, behind a labelled header toggle (which also amends §6's "three elements, no more" header rule to four). The .sf-root.dark scope re-derives the four light surfaces from the roast family; band rhythm, roast bands, chip, and flame are untouched. Brand red lifts to --brand-text #EE5B67 for text on dark (raw #CE1126 fails contrast there); the tip's pressed state moves to flame for the same reason. Admin stays light. The KDS scope shares no token with this and is unaffected. Contrast table to be recomputed for the dark pairs before anything ships.

    • Placeholders still in force (Open Inputs §9)

  • Text wordmark in Alfa Slab One, brand on paper — no logo yet.
  • #CE1126 as brand red, declared once in the token block.
  • Paper-sunk initial tiles in every 4:3 frame — no photography yet.
  • Tip presets shown are the configured values; default selection untouched.
  • Gizzards shown with zero modifier groups — the unbound-majority case renders correctly.

    • Mockup caveats

  • Fonts load from Google Fonts in this file only; production stays self-hosted subset WOFF2 (font-src 'self').
  • All money figures are static fixtures. The modal's "live price" is faked here; in production it and every checkout figure come from the server quote.
  • This file is presentation only — nothing here implies any behaviour change. Sprint 16 deploys first, then Sprint 14, then any of this.
